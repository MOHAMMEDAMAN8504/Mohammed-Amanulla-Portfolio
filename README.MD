Welcome to my personal 3D Developer Portfolio! This interactive web application is designed to showcase my software development journey, technical skills, projects, and credentials through an engaging, modern 3D user interface.

Built using **React**, **Three.js** (via React Three Fiber), and **Tailwind CSS**, the portfolio features interactive 3D canvas objects, sleek glassmorphism panels, premium animations, and a responsive contact form with interactive elements.

## 🛠️ Tech Stack & Key Libraries

*   **Frontend Framework**: React.js (Vite)
*   **3D Graphics & Canvas**: Three.js, `@react-three/fiber`, `@react-three/drei`
*   **Animations**: Framer Motion, GSAP
*   **Styling**: Custom CSS & Tailwind CSS
*   **Icons & Interactive FX**: FontAwesome, React Confetti, React Hot Toast

## 🚀 Running Locally

To download the repository and boot the local Vite server:

1.  Clone the repository:
    ```bash
    git clone https://github.com/MOHAMMEDAMAN8504/react-threejs-portfolio-main.git
    cd react-threejs-portfolio-main
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Launch local development server:
    ```bash
    npm run dev
    ```
    Open `http://localhost:5173` in your browser!

4.  Compile production build:
    ```bash
    npm run build
    ```
